AIS Analytics — Documentazione Servizi

Portale di accesso alla documentazione AsyncAPI dei worker di elaborazione dati AIS (Automatic Identification System). Ogni servizio consuma messaggi NMEA/AIVDM dal bus Kafka e produce analisi specifiche per il dominio portuale.

Bridge Delta ETA
bridge-deltaeta · analytics_ais.raw
Calcola lo scostamento (delta_min) tra l'ETA dichiarata dalla nave via AIS e l'orario di arrivo pianificato recuperato dal backend REST. Un valore positivo indica ritardo, negativo indica anticipo. Supporta la simulazione tramite SIM_SPEED_FACTOR per comprimere il tempo di percorrenza simulato. Pubblica un evento per nave ogni PUBLISH_INTERVAL secondi.
consume: ais.raw consume: ais_simulation.raw publish: analytics_ais.raw GET /percorso/by_mmsi/{mmsi}

Bridge Banchina
bridge-banchina · analytics_ais.raw
Aggrega le navi in arrivo per banchina/destinazione, filtrando quelle con ETA entro la finestra temporale WINDOW_FUTURE_MIN. Ogni PUBLISH_INTERVAL secondi emette un evento BerthIncomingEvent con la lista ordinata per ETA crescente delle navi dirette verso ciascuna banchina attiva.
consume: ais.raw consume: ais_simulation.raw publish: analytics_ais.raw
→
:9002
Bridge Components
bridge-components · analytics_ais.raw
Traccia il tempo di utilizzo (usage_seconds_total) di ciascun componente di bordo installato sulle navi in movimento (SOG > 0.1 nodi). I componenti vengono recuperati via REST con cache TTL configurabile. Pubblica un ComponentUsageEvent per ogni coppia (MMSI, componente) attiva ogni PUBLISH_INTERVAL_SEC secondi.
consume: ais.raw consume: ais_simulation.raw publish: analytics_ais.raw GET /componente/by_mmsi/{mmsi}
→
:9003
Decoder AIS FastStream
decoder-ais-faststream · ais_decoded.raw / ais_decoded_simulation.raw
Decodifica i frame NMEA/AIVDM grezzi (ITU-R M.1371) tramite pyais e normalizza il risultato in eventi AisDecodedEvent strutturati con posizione, SOG, COG, tipo messaggio AIS e payload statico (Tipo 5). Gestisce messaggi multipart con buffer a coda TTL 120s. Due istanze separate: main (AIS reale) e sim (simulazione).
consume: ais.raw consume: ais_simulation.raw publish: ais_decoded.raw publish: ais_decoded_simulation.raw
→
:9004
Bridge Arrivo
bridge-arrivo · REST PATCH /assegnazione/{id}/stato
Rileva l'arrivo della nave a destinazione tramite geofencing haversine (raggio GEOFENCE_RADIUS_M). Implementa una state machine per nave: navigating → arriving → arrived. Dopo ARRIVAL_CONFIRM_COUNT check consecutivi all'interno del geofence, chiama il backend REST per segnare l'assegnazione come COMPLETATA. Nessun output su Kafka — l'unico effetto è la chiamata REST.
consume: ais.raw consume: ais_simulation.raw PATCH /assegnazione/{id}/stato GET /percorso/by_mmsi/{mmsi}
